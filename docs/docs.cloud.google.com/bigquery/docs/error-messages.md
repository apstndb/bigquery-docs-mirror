# Error messages

This document describes client-side, proxy, connectivity, and Google Cloud console error messages that you might encounter when working with BigQuery.

- For HTTP status codes and API error messages returned by the BigQuery API, see [HTTP status and error codes for BigQuery API](https://docs.cloud.google.com/bigquery/docs/errors) .
- For more information about query errors, see [Troubleshoot query errors](https://docs.cloud.google.com/bigquery/docs/troubleshoot-queries) .
- For more information about access control and authentication errors, see [Troubleshoot access control issues](https://docs.cloud.google.com/bigquery/docs/troubleshoot-access-control) .
- For more information about streaming insert errors, see [Troubleshoot streaming inserts](https://docs.cloud.google.com/bigquery/docs/write-api-rest#troubleshooting) .
- For more information about client library errors and objects, see [BigQuery API client libraries](https://docs.cloud.google.com/bigquery/docs/reference/libraries) .

## Error table

If you use the [bq command-line tool](https://docs.cloud.google.com/bigquery/docs/reference/bq-cli-reference) to check job status, the error object isn't returned by default. To view the error object and the corresponding `reason` property, use the `--format=prettyjson` flag—for example, `bq --format=prettyjson show -j <var>JOB_ID</var>` . To view verbose logging for the bq tool, use `--apilog=stdout` . To learn more about troubleshooting the bq tool, see [Troubleshooting CLI commands](https://docs.cloud.google.com/bigquery/docs/reference/bq-cli-reference#troubleshooting-bq) .

The following table lists client-side and proxy error messages that aren't returned directly by the BigQuery API:

| Error message               | HTTP code | Description                                                                                                                                                                                                   | Troubleshooting                                                                                                                                                                                                                                                            |
|-----------------------------|-----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| attributeError              | 400       | User code references an object attribute that does not exist.                                                                                                                                                 | Ensure that the object you're working with has the attribute you're trying to access. For more information about this error, see [AttributeError](https://docs.python.org/3/library/exceptions.html#AttributeError) .                                                      |
| proxyAuthenticationRequired | 407       | The client request lacks valid authentication credentials for the proxy server. For more information, see [407 Proxy Authentication Required](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/407) . | Troubleshooting is specific to your environment. If you receive this error while working in Java, ensure you have set both the `jdk.http.auth.tunneling.disabledSchemes=` and `jdk.http.auth.proxying.disabledSchemes=` properties with no value following the equal sign. |

## Google Cloud console error messages

The following table lists error messages that you might see while you work in the Google Cloud console.

| Error message                           | Description                                                                                                                                                                               | Troubleshooting                                                                                                                                                                                                                                                                                                           |
|-----------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Unknown error response from the server. | This error appears when the Google Cloud console receives an unknown error from the server; for example, when you click a dataset or other type of link, and the page can't be displayed. | Switch to your browser's incognito, or private, mode and repeat the action that resulted in the error. If no error results in incognito mode, then the error might be due to a browser extension, such as an ad blocker.
