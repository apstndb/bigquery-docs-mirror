## Tool: `trace_lineage`

Traces the data lineage of a source data warehouse from its query logs and metadata. Before calling this tool, extract metadata and query logs from the source system as .ZIP files using `gcloud alpha bq migration metadata extract` and `gcloud alpha bq migration query-logs extract` . Then, upload the files to a Cloud Storage folder using `gcloud storage rsync` , and pass the folder in `source_base_uri` . Supported source systems are Teradata, Redshift, Snowflake, and BigQuery. The lineage service processes the first 5 GB of the oldest query logs. Tracing runs asynchronously and can take several hours for large inputs. Use the `get_lineage` tool with the lineage ID returned in `name` to poll its state until it is `SUCCEEDED` or `FAILED` . Wait at least 30 seconds before rechecking the state.

The following code sample shows how to use `curl` to call the `trace_lineage` MCP tool.

**Curl Request**

```
curl --location 'https://bigquerymigration.googleapis.com/mcp' \
--header 'content-type: application/json' \
--header 'accept: application/json, text/event-stream' \
--data '{
  "method": "tools/call",
  "params": {
    "name": "trace_lineage",
    "arguments": {
      // Provide these details according to the MCP tool specification.
    }
  },
  "jsonrpc": "2.0",
  "id": 1
}'
```

### Tool Annotations

[Tool annotations](https://modelcontextprotocol.io/specification/latest/schema#toolannotations) are sent to MCP clients to describe the basic risk of a given tool. Most clients treat these hints as untrusted, but they can be used to decide when a confirmation prompt might be sent to a user.

Along with the title string, the following boolean hints are defined as follows:

- `readOnlyHint` : If true, the tool doesn't modify its environment. Default: false.
- `destructiveHint` : If true, then the tool can perform destructive actions. If false, then the tool can only perform additive actions. Default: true.
- `idempotentHint` : If true, then calling the tool repeatedly with the same arguments will have no additional effect on its environment. Default: false.
- `openWorldHint` : If true, then the tool can interact with an 'open world' of external entities. If false, then the tool can only interact with internal entities. For example, a web search tool would be open world, while a memory tool would not be open world.
