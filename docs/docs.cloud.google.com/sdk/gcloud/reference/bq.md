NAME

gcloud bq - manage Bq resources

SYNOPSIS

`gcloud bq` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/bq#GROUP) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/bq#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Manage Bq resources.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`migration-workflows`](https://docs.cloud.google.com/sdk/gcloud/reference/bq/migration-workflows)  
Manage Migration Workflow resources.

NOTES

These variants are also available:

```
gcloud alpha bq
```
