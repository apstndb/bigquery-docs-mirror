NAME

gcloud alpha bq migration validation - validate data migrated to BigQuery against its source

SYNOPSIS

`gcloud alpha bq migration validation` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration/validation#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration/validation#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

`(ALPHA)` Validate data migrated to BigQuery against its source.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`configure`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration/validation/configure)  
`(ALPHA)` Generate the configuration for validating migrated data.

[`run`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration/validation/run)  
`(ALPHA)` Validate data migrated to BigQuery against its source.

REGIONAL ENDPOINTS

This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ `[`gcloud config set`](https://docs.cloud.google.com/sdk/gcloud/reference/config/set)` regional/endpoint_mode regional-preferred` .

NOTES

This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
