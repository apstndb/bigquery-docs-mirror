NAME

gcloud alpha bq migration translation - manage BigQuery Migration Service translations

SYNOPSIS

`gcloud alpha bq migration translation` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration/translation#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration/translation#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

`(ALPHA)` Manage BigQuery Migration Service translations.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration/translation/describe)  
`(ALPHA)` Get the details or status of a submitted translation.

[`generate-source-ddl`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration/translation/generate-source-ddl)  
`(ALPHA)` Generates source DDL schemas from a batch of SQL queries using AI.

REGIONAL ENDPOINTS

This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ `[`gcloud config set`](https://docs.cloud.google.com/sdk/gcloud/reference/config/set)` regional/endpoint_mode regional-preferred` .

NOTES

This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
