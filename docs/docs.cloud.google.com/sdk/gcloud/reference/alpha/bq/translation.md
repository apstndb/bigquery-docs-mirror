NAME

gcloud alpha bq translation - manage BigQuery Migration Service translations

SYNOPSIS

`gcloud alpha bq translation` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/translation#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/translation#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

`(ALPHA)` Manage BigQuery Migration Service translations.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/translation/describe)  
`(ALPHA)` Get the details or status of a submitted batch translation.

[`generate-source-ddl`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/translation/generate-source-ddl)  
`(ALPHA)` Generates source DDL schemas from a batch of SQL queries using AI.

[`translate`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/translation/translate)  
`(ALPHA)` Translate a SQL query from a source dialect to BigQuery.

[`translate-batch`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/translation/translate-batch)  
`(ALPHA)` Translates a batch of SQL queries.

[`translate-metadata`](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/translation/translate-metadata)  
`(ALPHA)` Translates metadata from zip files into DDL statements and table mappings.

NOTES

This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
